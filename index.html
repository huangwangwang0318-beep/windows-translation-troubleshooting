Diagnose translation software by failure stage

Separate download, installation, startup, network, embedded-browser, OCR and document problems before changing the system.

Start with the symptom, not a reinstall

First record what still works. A successful home-screen launch does not prove that the installer host, sign-in service, document-upload endpoint, OCR service or translation API is reachable. Use a short sentence and a small redacted file so each layer can be tested independently.

Evidence worth preserving

  • Application and Windows versions
  • Exact error text and timestamp
  • Installer filename, size and signature result
  • Whether plain text, image OCR and document upload fail separately
  • Proxy or VPN state and the result of one permitted alternative network

Change only one setting per test. Avoid registry cleaners, random DLL downloads, certificate bypasses and blanket firewall disabling; these steps destroy useful evidence and can create a larger security problem.
